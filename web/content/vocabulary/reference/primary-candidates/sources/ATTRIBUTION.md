# Source Attribution and Use

## CEFR-J Vocabulary Profile 1.5

The candidate inventory uses the CEFR-J Vocabulary Profile Version 1.5 as an
external source for headwords, parts of speech, A1/A2 source levels, and source
topic evidence.

- Dataset: CEFR-J Vocabulary Profile Version 1.5
- Compiler: Yukio Tono, Tokyo University of Foreign Studies
- Repository mirror: https://github.com/openlanguageprofiles/olp-en-cefrj
- Original project: http://www.cefr-j.org/download.html
- Retrieved for this package: 2026-07-20

The Open Language Profiles repository states that the CEFR-J vocabulary and
grammar profile datasets may be used for research and commercial purposes at
no charge when properly cited. Copyright remains with Tono Laboratory at TUFS.
The source also disclaims responsibility for inaccuracies or damages.

Consult the source repository's current terms before distribution. Keep this
attribution file with any redistributed derivative dataset.

## Project-owned additions

The digital-literacy, platform-navigation, social-emotional, sustainability,
Global Studies, mathematics, and science extensions in the build script are
project curriculum decisions. They are not represented as official CEFR-J or
Council of Europe vocabulary assignments.

## CEFR interpretation

CEFR describes language proficiency and does not prescribe one definitive
English wordlist. `sourceCefr` records CEFR-J evidence. `cefrBandCandidate` and
`primaryStageCandidate` are internal curriculum fields requiring human review.
