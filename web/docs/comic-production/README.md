# WKE Comic Production System

This folder is the working source of truth for the WKE educational comic series.

## Start here

- `MASTER_BIBLE.md` - series purpose, confirmed canon, visual rules, language rules, and production workflow.
- `canon/series-canon.json` - machine-readable identities and production facts.
- `canon/chapter-01.md` - canonical record of the completed first chapter.
- `canon/chapter-02.md` - working record for Chapter 2.
- `references/character-model-lock.md` - visual identity rules for Mia, Zara, Leo, Ethan, and Keelan.
- `references/visual/model-sheets/` - canonical v1 turnarounds, expressions, clothing, and prop references for all five characters.
- `references/visual/fixed-crash-site-scene-map.svg` - fixed geography, character positions, prop locations, and camera-axis rule.
- `references/visual/fixed-crash-site-scene-map.png` - easy-to-preview raster copy of the map.
- `references/a1-a2-language-guide.md` - language controls for learners aged 9-12.
- `templates/` - reusable chapter, page-script, and image-prompt templates.
- `checklists/page-continuity-checklist.md` - required review before artwork is approved.
- `source-pages/` - canonical and alternate page artwork received during production.
- `audits/chapter-01-documentation-audit.md` - page-by-page Chapter 1 review against current character, scene, language, learning, and technical standards.
- `EDITABLE_COMIC_FORMAT.md` - layered art, editable lettering, teacher workflow, student interactions, and recommended next extensions.
- `references/visual/chapter-01-clean-art-prompts-v1.md` - reproducible clean-art edit instructions and page continuity constraints.

## Authority labels

- **Confirmed** - explicitly confirmed by the project owner.
- **Observed** - visible in approved artwork but not separately confirmed.
- **Working standard** - recommended production rule that may still be revised.
- **TBD** - deliberately unresolved; do not invent a permanent answer.

When files disagree, use the newest explicit owner decision, then update both `MASTER_BIBLE.md` and `canon/series-canon.json`.
