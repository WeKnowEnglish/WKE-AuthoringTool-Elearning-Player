# Character Model Sheets v1

These five files are the canonical visual references for Chapter 2 production:

- `mia-model-sheet-v1.png`
- `zara-model-sheet-v1.png`
- `leo-model-sheet-v1.png`
- `ethan-model-sheet-v1.png`
- `keelan-model-sheet-v1.png`

Each sheet supplies a front, three-quarter, strict side, and back view plus the character’s core expression library. Human sheets also lock clothing, color-symbol identity, and recurring props. Keelan’s sheet additionally locks hand/foot anatomy and the blue-white magic effect.

Use the complete model in `../../character-model-lock.md` when reviewing a page. Do not crop a single pose and treat it as the whole authority. If a deliberate redesign is approved, preserve these files and create `*-model-sheet-v2.png` rather than overwriting version 1.
