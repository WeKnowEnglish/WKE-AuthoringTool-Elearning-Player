# Curriculum authoring

Start with the [unit-builder guide](./unit-builder-guide.md) and duplicate the [unit planning template](./unit-planning-template.md).

The guide defines the shared learning commitments: six distinct dedicated focus lessons, flexible unit length and order, introduction and review, guided-to-independent progression, spaced retrieval, differentiation and a bridge to the next unit. It is a teacher authoring standard; automatic enforcement and adaptive scheduling are not implemented by these documents.
