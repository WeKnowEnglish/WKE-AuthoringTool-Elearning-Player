# Phase 0 — Research & Framework (Detailed Plan)

**Goal:** Agree on hierarchy rules, source priorities, and domain outlines **before** writing concept nodes in Phase 1.

**Duration:** 1–2 weeks (~8–12 hours focused work)

**Exit gate:** You can explain without notes where Short answers sits in the existential chain, what a micro-skill is vs a concept, and which source you use when A1/A2 ordering conflicts.

## Sessions (recommended order)

### Session A — Orientation (60–90 min)

- Read README, PROGRESSION-PRINCIPLES, ID-NAMING, POSTER-TO-RESEARCH-MAP
- Log Session A in EXTRACTION-LOG: your preferred teaching order for the 8 posters

### Session B — EGP / CEFR (2–3 hours)

- Search EGP for: there is, there are, countable, uncountable, some, any, plural
- Use Worksheet A in RESEARCH-WORKSHEET; log paraphrased descriptors + CEFR band
- Update existential.md §EGP alignment

### Session C — YLE + primary ages (1.5–2 hours)

- Map Starters/Movers/Flyers to existential + noun concepts
- Use Worksheet B; update nouns.md §Age calibration

### Session D — Existential deep dive (2–3 hours)

- Complete existential.md: L3 chain, L4 per poster card, error families
- Draw: affirmative → questions → short_answers
- **Target: ≥80% complete** (main Phase 0 milestone)

### Session E — Nouns + determiners (2 hours)

- nouns.md ≥50%: countability contrast, plural successor chain
- determiners.md ≥50%: some/any precursors

### Session F — Sign-off (60–90 min)

- Run exit checklist below; freeze ID-NAMING v0.1
