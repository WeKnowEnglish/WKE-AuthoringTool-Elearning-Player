# GKE Review Checklist

Use before marking any L3 concept `status: published` in Phase 1+.

## Concept (L3)

- [ ] ID follows [ID-NAMING.md](./ID-NAMING.md)
- [ ] Parent L2 system exists
- [ ] Teacher label clear; student label ≤ 6 words if shown to kids
- [ ] At least one **function** statement (what the learner can do)
- [ ] CEFR band set with EGP or syllabus note
- [ ] `strandIds` includes `language_focused_learning` or other strands as needed
- [ ] Precursors listed OR marked `domain_entry`
- [ ] At least one L4 micro-skill linked
- [ ] No duplicate concept overlapping another L3

## Micro-skill (L4)

- [ ] Assesses one clear skill (not whole poster)
- [ ] Positive example sentence is primary-appropriate
- [ ] Error codes use `error.*` namespace
- [ ] Maps to at most one poster card (or note if spans cards)

## Progression edges

- [ ] Precursor/successor direction matches [PROGRESSION-PRINCIPLES.md](../PROGRESSION-PRINCIPLES.md)
- [ ] Contrast pairs are truly confusable, not just related topics

## Phase 0 only

- [ ] Existential domain reviewed by ESL lead
- [ ] ID-NAMING v0.1 frozen
